# Python 少儿编程入门课

> 给 11 岁、六年级、零基础小朋友的 Python 启蒙课。
> 目标：**兴趣优先** —— 几乎每节课结束时，屏幕上都能留下一个会动、能玩、好看的东西。

---

## 一、这门课是干嘛的

- **用什么教**：Python + `turtle`（海龟画图）。turtle 是 Python 自带的，零安装、天然可视化，能画图、能动画、还能做小游戏（接苹果、打砖块、贪吃蛇）。
- **全程只用标准库**：`print` / `input` / `turtle` / `random` / `time`，每个示例 `python xxx.py` 直接能跑，**不用装任何第三方包**。
- **语言约定**：代码关键字是英文（没办法），但注释、变量名含义、讲解全部用中文，门槛最低。

---

## 二、怎么用这个工程

工作流程很简单：

1. 你只要说「**教第 X 课**」，我就生成那一课的文件夹，包含：
   - `slides.html` —— 网页幻灯片（双击浏览器打开，键盘翻页）
   - `demo.py` —— 课堂示例（直接运行）
   - `challenge.py` —— 挑战题（学有余力的加餐，可选）
   - `teaching-notes.md` —— 给你的讲稿：怎么讲、关键点、孩子会卡在哪
2. 你照着 `teaching-notes.md` 讲，孩子看幻灯片、跑 `demo.py`、动手改着玩。

## 三、环境准备（第 0 步，先做一次）

1. 安装 Python 3（建议 3.10 及以上）：
   - 打开 <https://www.python.org/downloads/> 下载 Windows 安装包
   - 安装时**务必勾选 `Add Python to PATH`**
2. 验证装好了：打开命令行（PowerShell / CMD），输入
   ```
   python --version
   ```
   能显示版本号（比如 `Python 3.12.x`）就成功了。
3. 跑一个示例：进入对应课文件夹，输入
   ```
   python demo.py
   ```

## 六、给家长的教学建议

1. **一次 20~30 分钟**：孩子注意力有限，一课一个核心概念，别贪多。
2. **每课都有"看得见的成果"**：结束时屏幕上留一个会动/能玩/好看的东西，这是兴趣优先的落地方式。
3. **让孩子多动手改**：改个颜色、改个数字、改个速度，观察结果变化，比死记语法有效得多。
4. **挑战题不硬性**：学得快就加餐，卡住就跳过，保护兴趣最重要。
5. **别急着纠错**：先让孩子把想法说出来、跑一跑看报错，再一起找原因 —— 调试本身就是很好的学习。
