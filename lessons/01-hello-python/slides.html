什么是编程？

  • 编程 = 给电脑下指令
  • 就像给机器人写一本「说明书」
  • 你写什么，电脑就做什么
  • Python 就是写说明书用的"语言"

print() 打印

让电脑把文字显示到屏幕上

文字要放在双引号 " " 里

# 把"你好"打印出来
print("你好！")

想说什么就写什么

中文、英文、数字，都可以放进双引号里

print("我喜欢打游戏")
print("I love Python")
print("我的学号是 6")

换行 \n

在文字里写 \n，表示"从这里换一行"

print("第一行\n第二行\n第三行")

第一行
第二行
第三行

一次打印多个

用逗号 , 把要打印的东西连起来

还能打印表情符号 🎮 ✨ 🦆

print("我", "会", "说话")

我 会 说话

# 是注释

注释是写给自己看的"便签"，电脑会忽略它

# 我是笔记，不会被打印
print("这一句才会被打印")
