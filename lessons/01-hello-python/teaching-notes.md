# 第 1 课 讲稿：你好，Python！

> 目标：让孩子亲手让电脑"开口说话"，建立"我能让电脑听我的话"的成就感。
> 时长建议：20~30 分钟。**只讲 print 一个概念**，别贪多。

---

## 课前准备

- 确认电脑已装好 Python（命令行输入 `python --version` 能显示版本号）。
- 打开 `slides.html`（双击，浏览器里翻页）。
- 把 `demo.py` 准备好，孩子会自己运行。

---

## 讲解流程（照着走就行）

### 第 1 步：先聊两句（2 分钟）
开场别讲语法，先建立兴趣：

> "你有没有想过，手机里的游戏、动画片，其实都是人用'语言'指挥电脑做出来的？今天我们就学一句最神奇的咒语，让电脑听你的话。"

### 第 2 步：什么是编程（幻灯片 2）
用"给机器人写说明书"这个比喻。核心一句话：**你写什么，电脑就做什么。**

### 第 3 步：print()（幻灯片 3~6）
- 先演示一遍：打开命令行，进入本文件夹，输入 `python demo.py`，让孩子**亲眼看到**电脑打印出一行行字。
- 然后回到代码，指着 `print("你好，我是电脑！")` 讲：
  - `print` = 打印（把文字显示出来）
  - 括号里的文字要放在**双引号**里，双引号是"文字的包装纸"
- 让孩子自己改一处：把 `"你好，我是电脑！"` 改成 ta 想说的话，再运行一次。**这一步一定要做**，改了就重跑，孩子会很有感觉。

### 第 4 步：换行和注释（幻灯片 5、7）
- `\n`：讲成"文字里的回车键"。
- `#`：讲成"写给自己看的小便签，电脑假装没看见"。

### 第 5 步：小彩蛋（幻灯片 9）
- demo.py 最后一段会用 `input()` 问名字。**故意先不解释原理**，就说："看，它还会叫你的名字！厉害吧？这个魔法下一课我们拆开看。"

---

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| `print()` | 让电脑把括号里的文字显示出来 |
| `"文字"` | 双引号是文字的"包装纸"，文字必须包在里面 |
| `\n` | 文字里的"回车键"，表示换行 |
| `#` | 写给自己看的便签，电脑会忽略 |

---

## 孩子可能卡在哪

1. **忘了打双引号** → 会报错 `NameError`。这是好机会，带孩子看报错，说："电脑找不到'包装纸'，不知道这是文字。"
2. **中英文标点混用** → 引号、括号必须是**英文**的 `"` `(` `)`。中文的 `"` 不行。这是新手第一常见坑，提前提醒。
3. **乱码** → 示例代码开头已经加了"防乱码开关"（那几行 `import sys` / `reconfigure`），一般不会乱码。如果个别终端还是乱码：
   - 优先用 **Windows Terminal** 或 VS Code 自带的终端跑。
   - 或在命令行先输入 `chcp 65001` 再运行。
