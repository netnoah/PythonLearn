数字魔法师

今天让电脑帮我们算数，还能记住数字~

变量：贴了标签的盒子

变量就像一个小盒子，上面贴着名字，里面装着东西

# 把 100 放进叫 coins 的盒子
coins = 100

# 把"小明"放进叫 name 的盒子
name = "小明"

数字不用引号，文字要引号

= 不是"等于"

在 Python 里，= 的意思是"放进盒子里"

coins = 100
# 读作：把 100 放进 coins 盒子

跟数学里的"等于"不一样哦！

数字的四则运算

100 + 30   # 加 = 130
100 - 20   # 减 = 80
100 * 3    # 乘 = 300（用 * 不是 ×）
100 / 4    # 除 = 25.0（用 / 不是 ÷）

input()：让程序听你说话

input() 会停下来，等你打字，再把你打的字还给程序

name = input("你叫什么？")

你打的字会被放进 name 这个盒子里

⚠️ 重点

input 拿到的是"文字"

你输入的 1 和 2，程序眼里是文字 "1" "2"

text_a = input("输入第一个数：")  # 你输入 1
text_b = input("输入第二个数：")  # 你输入 2

print(text_a + text_b)   # 结果不是 3，而是 "12"！

因为文字相加是"拼接"，不是"计算"

int()：把文字变成数字

想真正算数，先用 int() 把文字变成数字

int 是 integer（整数）的缩写

int("100")   # 变成数字 100

print(int(text_a) + int(text_b))  # 1 + 2 = 3 ✓

完整例子：零花钱计算器

money = int(input("零花钱有多少？"))
cost  = int(input("想买的东西多少钱？"))
left  = money - cost

print("买完后你还剩", left, "元")
