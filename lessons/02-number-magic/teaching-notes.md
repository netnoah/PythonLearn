> 目标：学会变量、四则运算、`input()`，并搞懂本课**最关键**的一个点——`input()` 拿到的是"文字"，要 `int()` 才能算数。
> 时长建议：25~35 分钟。本课信息量比第 1 课大，可以适当放慢。

## 课前准备

- 确认第 1 课已经跑通过（孩子对 `print` 有感觉了）。
- 打开 `slides.html`，准备好 `demo.py`。

## 讲解流程

### 第 1 步：变量 = 贴标签的盒子（幻灯片 2~3）
- 讲"盒子"比喻：变量就是一个有名字的盒子，`=` 是"放进去"，不是"等于"。
- **务必强调** `=` 和数学里"等于"不一样，这是孩子最容易混的点。
- 让孩子区分：`name = "小明"`（文字要引号）vs `coins = 100`（数字不要引号）。

### 第 2 步：四则运算（幻灯片 4）
- 直接演示 `python demo.py`，看电脑算 `+ - * /`。
- 两个小坑提前说：
  - 乘号是 `*`，不是 `×`；除号是 `/`，不是 `÷`。
  - 除法结果会带小数点：`100 / 4` 显示 `25.0`。告诉孩子"25.0 就是 25，Python 的小习惯，先不用管"。

### 第 3 步：input() 让程序听你说话（幻灯片 5~7）★本课重点
- 先演示 input 的效果：程序停下来等你打字。
- **重点讲解"文字 vs 数字"**（幻灯片 6 的陷阱）：
  - 你输入的 `1`、`2`，程序当成文字 `"1"`、`"2"`。
  - 文字相加是"拼接"：`"1" + "2" = "12"`，不是 3。
  - 所以要先 `int()` 变成数字，才能真算数。
- 这个点一定要让孩子**亲手跑一遍 demo.py 的第三段**，看到"直接相加 = 12"和"转换后 = 3"的对比，印象才深。

### 第 4 步：零花钱计算器（幻灯片 8）
- 这是本课的"成果"：一个真正能用的计算器。
- 让孩子输入自己的零花钱和想买的东西价格，看电脑算出剩余。

---

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| 变量 | 贴了标签的盒子，`=` 把东西放进去 |
| `=` | 是"放进去"，不是"等于" |
| `+ - * /` | 乘用 `*`，除用 `/` |
| `input()` | 让程序停下来听你打字，返回的是"文字" |
| `int()` | 把文字变成整数（integer） |

---

## 孩子可能卡在哪

1. **`"1" + "2" = "12"` 看不懂** → 用生活例子：把两张字条"1"和"2"贴在一起，得到的是"12"这张字条，不是数字 3。想算数，得先把字条翻译成数字。
2. **忘了 `int()`** → 直接 `input()` 后拿来算，会报错（`TypeError`）或拼成字符串。这是本课最典型的错，属正常，耐心引导。
3. **文字和数字混用** → 提醒：数字不加引号（`100`），文字加引号（`"100"`）。`"100"` 是文字，`100` 是数字，两者不一样。
4. **`=` 当成了"等于"** → 每次出现 `coins = coins + 50`，孩子会懵（"100 怎么等于 150？"）。解释：先算右边的 `coins + 50`，再把结果"放进"左边盒子里。这是理解赋值的关键。
5. **除法带 `.0`** → 说明是 Python 小习惯，25.0 就是 25，以后会细讲。
