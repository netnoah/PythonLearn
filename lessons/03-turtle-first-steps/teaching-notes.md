# 第 3 课 讲稿：小海龟登场

> 目标：让孩子指挥 turtle 海龟，画出第一个图形，感受"代码变成看得见的图案"。
> 时长建议：25~30 分钟。这是从"黑窗口"到"图形世界"的转折点，孩子通常会很兴奋。

---

## 课前准备

- 确认电脑有 Python（turtle 是自带的，不需要额外安装）。
- 打开 `slides.html`，准备好 `demo.py`。

---

## 讲解流程

### 第 1 步：先看效果（2 分钟）
- **先别讲代码**，直接运行 `python demo.py`，让孩子看：屏幕上弹出一个窗口，一只小海龟爬出来画了个正方形，又画了个三角形。
- 孩子往往会"哇"一下。趁这个情绪，说："这就是编程——你写命令，海龟照着爬，爬过的路就变成画。"

### 第 2 步：请出海龟（幻灯片 2~3）
- `import turtle` = 把"海龟工具箱"拿来。
- `t = turtle.Turtle()` = 造一只海龟，起名叫 `t`。
- 讲清楚：`t` 就是这只海龟，接下来所有命令都是对它说的。

### 第 3 步：4 个命令（幻灯片 4~6）
- `forward(100)` = 向前走 100 步；`backward` 向后。
- `left(90)` / `right(90)` = 转弯，数字是角度。
- 用"海龟转一圈是 360 度"建立角度概念：转 90 度 = 转四分之一圈。

### 第 4 步：画正方形和三角形（幻灯片 7~8）★数学亮点
- 正方形：4 条边，每边转 **90** 度（因为 360 ÷ 4 = 90）。
- 三角形：3 条边，每边转 **120** 度（因为 360 ÷ 3 = 120）。
- **这是孩子（喜欢数学）会喜欢的地方**：让他自己发现规律「360 ÷ 边数 = 每个角转的度数」，然后立刻就能推导出五边形该转 72 度、六边形转 60 度。
- 孩子如果问"为什么要 360 ÷ 边数"，就画给他看：海龟爬完一圈回到原地，总共转了 360 度。

### 第 5 步：turtle.done()（幻灯片 9）
- 最后一行 `turtle.done()` = "画完了，别关窗口，让我看"。
- 如果忘了这行，窗口会"一闪就没了"，这是本课最常见的坑。

---

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| `import turtle` | 把海龟工具箱拿来 |
| `t = turtle.Turtle()` | 造一只海龟，叫 `t` |
| `t.forward(n)` / `t.backward(n)` | 前进 / 后退 n 步 |
| `t.left(a)` / `t.right(a)` | 左转 / 右转 a 度 |
| `turtle.done()` | 画完别关窗口，让我看 |
| 转角度数 | 360 ÷ 边数 |

---

## 孩子可能卡在哪

1. **窗口一闪就没了** → 忘了 `turtle.done()`，或程序报错后窗口自动关。先检查有没有这行。
2. **`NameError: name 'turtle' is not defined`** → 忘了 `import turtle`。
3. **分不清 left 和 right** → 让孩子把手比作海龟：左手左转、右手右转。
4. **正方形和三角形转的角度搞混** → 回到"360 ÷ 边数"这个公式，比死记更牢。
5. **窗口弹到别的窗口后面去了** → 让孩子去任务栏找那个 turtle 窗口。
