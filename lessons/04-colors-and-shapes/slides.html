给世界涂上颜色

学会换颜色、填充、抬笔落笔，画出彩虹和小房子！

还记得小海龟吗？

  • import turtle 请出海龟
  • forward / backward 前进后退
  • left / right 左转右转
  • 上一课我们画的都是"黑线条"

今天，让画变得五颜六色！

新本领 ①：换颜色 pencolor

t.pencolor("red")    # 把笔换成红色
t.forward(100)      # 之后画的线都是红色

常用的颜色单词：

red orange yellow green blue purple

新本领 ②：抬笔 / 落笔

t.penup()       # 抬笔：走路不留线
t.forward(150)   # 悄悄挪个位置
t.pendown()     # 落笔：又能画画了

就像写字：抬起来挪位置，再放下来继续写

新本领 ③：填充颜色

t.fillcolor("gold")   # 里面涂什么色
t.begin_fill()        # 开始装颜料
t.forward(120)      # 画一个封闭图形……
t.left(120)
t.forward(120)
t.left(120)
t.forward(120)
t.end_fill()          # 结束：涂满啦！

小工具：背景 + 粗细

turtle.bgcolor("skyblue")  # 背景颜色（天空蓝）
t.pensize(12)              # 笔的粗细，越大越粗

小工具：画圆 circle

t.circle(50)        # 画一个整圆
t.circle(80, 180)   # 画半个圆（一道弧）

彩虹就是靠"半圆"一层套一层画出来的！

🌈

画彩虹

6 个半圆套在一起：

外圈红 → 橙 → 黄 → 绿 → 蓝 → 内圈紫

半径一圈比一圈小，就套成了彩虹

🏠

画小房子

  • 墙壁 = 填充的正方形（淡黄）
  • 屋顶 = 填充的三角形（红）
  • 门 = 填充的小长方形（棕）
