# 第 4 课 讲稿：给世界涂上颜色

> 目标：让孩子学会给海龟的画上色——换颜色、填充、抬笔落笔，最后画出一道彩虹和一座小房子。
> 时长建议：25~30 分钟。上完这课，孩子的画从"黑白线条"变成"彩色作品"，通常会很兴奋。

---

## 课前准备

- 确认电脑有 Python（turtle 是自带的，不需要额外安装）。
- 打开 `slides.html`，准备好 `demo.py`。

---

## 讲解流程

### 第 1 步：先看效果（2 分钟）
- 直接运行 `python demo.py`，让孩子看：先出现几个彩色图形，然后"擦掉"，画出一道彩虹，彩虹下面还有一座带门的小房子。
- 趁"哇"的时候说："上一课我们只会画黑线条，今天给它涂上颜色，是不是漂亮多了？"

### 第 2 步：换颜色 pencolor（幻灯片 3）
- `t.pencolor("red")` = 把笔换成红色，之后再画的线就是红色。
- 颜色单词用英文：red / orange / yellow / green / blue / purple。
- 让孩子自己改一个颜色，运行一次观察变化。

### 第 3 步：抬笔落笔 penup / pendown（幻灯片 4）
- `t.penup()` = 把笔抬起来，海龟走路就不留线。
- `t.pendown()` = 把笔放下来，又开始留线。
- 类比：就像你用笔写字，抬起来挪个位置，再放下来继续写。

### 第 4 步：填充 begin_fill / end_fill（幻灯片 5）
- `t.fillcolor("gold")` 选"里面涂什么色"，`t.pencolor(...)` 选"边框什么色"。
- `t.begin_fill()` 到 `t.end_fill()` 之间画的封闭图形，会被自动涂满。
- 关键：begin_fill 要在画图形**之前**，end_fill 在画**之后**，像一对括号包住图形。

### 第 5 步：小工具 bgcolor、pensize、circle（幻灯片 6~7）
- `turtle.bgcolor("skyblue")` = 背景颜色（天空蓝）。
- `t.pensize(12)` = 笔的粗细，数字越大线越粗。
- `t.circle(半径)` 画整圆，`t.circle(半径, 180)` 画半圆——彩虹就是靠半圆画出来的。

### 第 6 步：画彩虹（幻灯片 8）
- 彩虹 = 6 个"半圆"套在一起，从外圈的红，到内圈的紫。
- 每个半圆半径小一点（130 → 116 → … → 60），所以一层套一层。
- 这里重复写了 6 遍很像的代码，正好给下一课的"循环"埋个伏笔。

### 第 7 步：画小房子（幻灯片 9）
- 墙壁 = 填充的正方形（淡黄色）；屋顶 = 填充的三角形（红色）；门 = 填充的小长方形（棕色）。
- 这一步把今天学的三个本领（换色、填充、抬笔落笔）全都用上了。

### 第 8 步：动手改着玩（幻灯片 10）
- 让孩子改：换屋顶颜色、把门变大、给房子加一扇窗户。
- 提醒 `turtle.done()` 别忘，否则窗口一闪就没了。

---

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| `t.pencolor("red")` | 换笔（线）的颜色 |
| `t.fillcolor("gold")` | 选里面填充的颜色 |
| `t.penup()` / `t.pendown()` | 抬笔 / 落笔 |
| `t.begin_fill()` / `t.end_fill()` | 开始 / 结束填充 |
| `turtle.bgcolor("skyblue")` | 背景颜色 |
| `t.pensize(n)` | 笔的粗细 |
| `t.circle(r)` / `t.circle(r, 180)` | 画整圆 / 半圆 |

---

## 孩子可能卡在哪

1. **填充没效果** → 忘了 `begin_fill()` 和 `end_fill()` 这对"括号"；或顺序反了。
2. **忘了 pendown** → 抬笔后忘了落笔，结果后面什么都画不出来。
3. **颜色单词拼错** → 报 `TurtleGraphicsError: bad color`，对照颜色表重拼。
4. **窗口一闪就没了** → 忘了 `turtle.done()`。
5. **彩虹画歪了 / 只有一半** → 忘了 `setheading(90)` 让海龟朝上；或 `circle` 的半径没递减。
6. **房子和彩虹叠在一起** → 让孩子观察坐标：彩虹在上面（y 是正数），房子在下面（y 是负数）。

- 完成 `challenge.py`：画一个红绿灯（练填充 + 圆）。
- 加餐：画彩色旗帜、彩色小花、给房子加窗户。
- **预告下一课（第 5 课）循环的魔法**：像彩虹这种"重复 6 遍很像的代码"，一个 `for` 循环就能写完，还能画出螺旋、星星、雪花——给孩子留个期待。
