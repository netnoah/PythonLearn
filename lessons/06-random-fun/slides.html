随机大冒险

用 random 让程序"随机"，画一片每次都不一样的璀璨星空！

什么是随机？

  • 随机 = 每次都不一样，你猜不到结果
  • 像掷骰子 🎲、抽卡、抽奖
  • 游戏里的掉落、暴击，背后都是"随机"

把随机工具箱拿来

# 就像第 3 课请出海龟
import random

拿来了就能用随机，不用另外安装

掷骰子：randint

random.randint(1, 6)
# 在 1~6 之间随机挑一个整数

用循环掷 3 次：

for i in range(3):
    print(random.randint(1, 6))

随机挑一个：choice

colors = ["red", "yellow", "blue"]

random.choice(colors)
# 从列表里随机挑一个

星空里"随机颜色"就靠它

小工具：t.dot 画圆点

t.dot(6, "gold")
# 画一个直径 6 的金色实心圆点

用它画星星，比填充还简单

星空 = 循环 + 随机

for i in range(60):
    x = random.randint(-380, 380)
    y = random.randint(-280, 280)
    size = random.randint(2, 9)
    t.penup()
    t.goto(x, y)
    t.dot(size, random.choice(star_colors))
