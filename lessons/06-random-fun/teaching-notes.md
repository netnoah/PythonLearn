# 第 6 课 讲稿：随机大冒险

> 目标：让孩子学会用 `random` 让程序"随机"，配合循环画出一片每次都不一样的璀璨星空。
> 时长建议：25~30 分钟。"随机"这个概念对孩子天然有吸引力——游戏里的掉落、抽卡、骰子都靠它。

---

## 课前准备

- 确认电脑有 Python（random 和 turtle 都是自带的，不需要额外安装）。
- 打开 `slides.html`，准备好 `demo.py`。

---

## 讲解流程

### 第 1 步：先看效果（2 分钟）
- 直接运行 `python demo.py`。让孩子看**命令行**：先随机掷出 3 个骰子数、随机抽出 3 个颜色；再看**窗口**：夜空里撒满了大大小小、颜色不一的星星。
- 趁"哇"的时候问："如果我再运行一次，会一样吗？"——这就是随机。

### 第 2 步：什么是随机（幻灯片 2）
- 随机 = 每次都不一样，你猜不到结果，像掷骰子、抽卡。
- 游戏里的掉落、暴击、抽奖，背后都是"随机"。

### 第 3 步：import random（幻灯片 3）
- `import random` = 把"随机工具箱"拿来，就像第 3 课 `import turtle` 请出海龟。

### 第 4 步：random.randint(a, b)（幻灯片 4）
- 在 a 和 b 之间随机挑一个整数（**包括 a 和 b**）。
- `random.randint(1, 6)` 就是"掷骰子"。
- 让孩子在命令行里多跑几次，看每次数字都不一样。

### 第 5 步：random.choice(列表)（幻灯片 5）
- 从列表里随机挑一个。
- `random.choice(["红","黄","蓝"])` 随机返回其中一个。
- 这也是随机星空里"随机颜色"的来源。

### 第 6 步：小工具 t.dot（幻灯片 6）
- `t.dot(大小, 颜色)` = 画一个实心圆点，大小是直径（像素）。
- 用它画星星，比填充还简单。

### 第 7 步：星空 = 循环 + 随机（幻灯片 7）
- 回顾第 5 课的 `for` 循环：重复 60 次。
- 每一遍，位置（x、y）、大小、颜色都随机——所以星星散得满天空、大小颜色都不一样。
- 这是"循环"和"随机"的组合拳。

### 第 8 步：多运行几次（幻灯片 8）
- **这是本课最爽的一点**：每运行一次，星空都完全不同。
- 让孩子连续运行 3 次，对比三片星空。

### 第 9 步：动手改着玩（幻灯片 9）
- 改 `range(60)` 成 100、200 → 星星更多。
- 改 `random.randint(2, 9)` → 星星更大/更小。
- 改 `star_colors` 加颜色。

---

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| `import random` | 把随机工具箱拿来 |
| `random.randint(a, b)` | a~b 之间随机整数（含两端） |
| `random.choice(列表)` | 从列表随机挑一个 |
| `t.dot(大小, 颜色)` | 画实心圆点 |
| 循环 + 随机 | 重复做，但每次结果随机 |

---

## 孩子可能卡在哪

1. **忘了 import random** → 报 `NameError: name 'random' is not defined`。
2. **randint 拼写/逗号错** → `randint` 全小写、括号里两个数用逗号隔开。
3. **星星"太小看不见"** → `dot` 的直径最小是 2，可以调大 `random.randint(2, 9)` 看明显一点。
4. **星星重叠/挤在一起** → 这是随机的正常现象，正好讲"随机就是不可预测"。
5. **以为会无限循环** → `for i in range(60)` 只画 60 颗，不会无限；改大数字就画更多。
