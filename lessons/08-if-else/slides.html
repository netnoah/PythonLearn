程序会思考了

  • 以前：程序只会照着做
  • 现在：程序能看情况做不同的事
  • 比如：猜对了说"对"，猜错了说"错"

这就是 if / else

比较运算符

==  等于      !=  不等于
>   大于      <   小于
>=  大于等于  <=  小于等于

比较的结果是 True 或 False

True 和 False

print(5 > 3)   # 5 比 3 大，对 → True
print(5 == 3)  # 5 等于 3？错 → False

True = 对，False = 错，像开关的开/关

if / else 语法

if 条件:
    # 条件对，做这里
else:
    # 否则做这里

冒号 : 和缩进是关键（和第 5 课循环一样）

== 和 = 别搞混！

=   赋值：把东西装进去
x = 5

==  比较：是不是相等
x == 5

判断时写错成 = ，程序就会"傻掉"

猜数字小游戏

secret = random.randint(1, 10)
guess = int(input("猜 1~10："))

if guess == secret:
    print("猜对啦！🎉")
else:
    print("猜错了……")

random + input + if/else 三个老朋友
