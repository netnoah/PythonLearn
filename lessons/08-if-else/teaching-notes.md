# 第 8 课 讲稿：如果…就…（if / else）

> 目标：让孩子学会 `if` / `else` 判断，让程序第一次"会思考"，做出猜数字小游戏。
> 时长建议：25~30 分钟。这是第三单元的开端，也是编程思维的一次大升级：从"照着做"到"看情况做"。

---

## 课前准备

- 确认电脑有 Python（random 自带）。
- 打开 `slides.html`，准备好 `demo.py`。
- 注意：本课回到**命令行**（不再用 turtle 画图），因为"判断"是逻辑，不是画画。

---

## 讲解流程

### 第 1 步：先看效果（3 分钟）
- 运行 `python demo.py`：先打印几个"比较"的结果（True/False），然后进入猜数字游戏——你输入一个数，程序告诉你猜对没有。
- 让孩子多玩两遍。说："以前程序只是照着做；现在它会**看情况**做不同的事，这就是'会思考'。"

### 第 2 步：比较运算符（幻灯片 3）
- 程序能"比较"两个数，结果只有 **True（对）** 或 **False（错）**。
- `==` 等于、`!=` 不等于、`>` 大于、`<` 小于、`>=` 大于等于、`<=` 小于等于。
- 在命令行试 `print(5 > 3)`，看它吐出 True。

### 第 3 步：True / False（幻灯片 4）
- 这是"对/错"两个值，就像开关的"开/关"。
- 让孩子多写几个比较，猜结果。

### 第 4 步：if / else 语法（幻灯片 5）
- `if 条件:` —— 条件对，就做下面缩进的代码。
- `else:` —— 否则（条件不对）做这里的代码。
- **冒号 `:` 和缩进**是关键（和第 5 课 for 循环一样）。

### 第 5 步：== 和 = 别搞混（幻灯片 6）★重点
- `=` 是**赋值**（把东西装进去），`==` 是**比较**（是不是相等）。
- 这是孩子最容易错的地方，一定要单独强调。

### 第 6 步：猜数字游戏（幻灯片 7）
- `random.randint(1, 10)` 出秘密数字（第 6 课）。
- `int(input(...))`：input 拿到的是"文字"，`int()` 把它变成数字。
- `if guess == secret:` 判断猜对没有。

### 第 7 步：动手改着玩（幻灯片 8）
- 把范围改成 1~100。
- 改成"猜硬币"、"判断奇偶数"。
- 提醒：想"猜大了/猜小了"需要 3 个分支，下一课学 `elif`。

---

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| `if 条件:` | 条件对，就做下面的事 |
| `else:` | 否则做这些 |
| `==` | 比较"相等" |
| `=` | 赋值（装进去） |
| `True` / `False` | 对 / 错 |
| `int(input(...))` | 把输入的文字变成数字 |

---

## 孩子可能卡在哪

1. **把 `==` 写成 `=`** → 判断变成赋值，结果永远"对"。这是头号大坑。
2. **忘了冒号 `:`** → `if score >= 60` 后面要加冒号，否则 `SyntaxError`。
3. **忘了缩进** → if/else 下面的代码要缩进（和 for 循环一样）。
4. **忘了 `int()`** → input 拿到的是文字（字符串），和数字比会报 `TypeError`。记住：`int(input(...))`。
5. **分不清 True/False** → 让孩子多写几个比较，观察输出，慢慢就有感觉了。
