复习：if / else

  • if / else 只能二选一
  • 可生活里经常要三选一、四选一
  • 比如：优秀 / 及格 / 加油

怎么办？请出 elif！

elif = 再不然如果

if 条件1:
    # 条件1 对，做这里
elif 条件2:
    # 否则如果条件2 对，做这里
else:
    # 都不对，做这里

elif 能加好多好多个分支

给分数评级

score = int(input("分数："))

if score >= 90:
    print("优秀！⭐⭐⭐")
elif score >= 60:
    print("及格 ⭐")
else:
    print("还要加油 💪")

95 分走第 1 条，70 分走第 2 条，50 分走最后

从上往下，一个个试

  • 程序从上往下依次检查条件
  • 第一个对的分支执行完，就停
  • 所以条件要从严格排到宽松
if score >= 90:   # 先看最高分
elif score >= 60: # 再看及格
else:             # 最后剩下

石头剪刀布

  • 石头 ✊ 砸 剪刀 ✌️
  • 剪刀 ✌️ 剪 布 ✋
  • 布 ✋ 包 石头 ✊

转着圈克制，没有绝对老大

和电脑猜拳

computer = random.randint(1, 3)  # 电脑出
player = int(input("1石头 2剪刀 3布："))

if player == computer:
    print("平局！")
elif player == 1 and computer == 2:
    print("石头砸剪刀，你赢啦！🎉")
# ……剪刀剪布、布包石头，共 3 个你赢

and = 而且

player == 1 and computer == 2
# 你出石头，而且电脑出剪刀

两个条件都满足，结果才是 True
