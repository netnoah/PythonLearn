一个完整的"会思考"的小游戏

记分牌

score = 0            # 先放 0 分

if 答对:
    score = score + 1   # 旧分 +1 再放回去

score = score + 1：右边先算，再放回左边

第 1 关：数字题

answer = int(input("3 + 5 等于几？"))

if answer == 8:
    print("答对啦！🎉")
    score = score + 1
else:
    print("答错啦")

数字题：int(input(...)) + ==

第 2 关：脑筋急转弯

answer = input("什么越洗越脏？")

if answer == "水":
    print("答对啦！🎉")
    score = score + 1
else:
    print("答案是「水」")

文字题：直接比字符串（带引号）

彩蛋关：随机单双

secret = random.randint(1, 10)
guess = input("单还是双？")

if secret % 2 == 0:
    right = "双"
else:
    right = "单"

random（第 6 课）+ % 判单双（第 5 课）

结算评级

if score == 4:
    print("满分！闯关大王！👑")
elif score >= 2:
    print("不错哦！⭐")
else:
    print("再试一次！💪")

elif 评级（第 9 课）
