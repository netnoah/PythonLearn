# 第 10 课 讲稿：谜题闯关（综合 if 小项目 🎯）

> 目标：这是第三单元的小项目，把第 8 课的 if/else、第 9 课的 elif，加上 int(input)、==、random、% 全部串起来，做一个趣味问答闯关。
> 时长建议：30 分钟。重点是让孩子感到"我把学过的判断都用起来了，能做出一个完整小游戏"。

---

## 课前准备

- 确认电脑有 Python（random 自带）。
- 打开 `slides.html`，准备好 `demo.py`。
- 本课在**命令行**（不用 turtle），因为"判断"是逻辑，不是画画。

---

## 讲解流程

### 第 1 步：先看效果（2 分钟）
- 运行 `python demo.py`：一道一道答题，答对加分，最后评级。
- 说："这一课不学新知识，把前两课学的判断都拿出来，做一个完整的问答闯关小游戏。"

### 第 2 步：回顾学过什么（幻灯片 2）
| 课 | 学到 |
|---|---|
| 第 8 课 | if / else、比较 == |
| 第 9 课 | elif、and |
| 第 5 课 | %（求余） |
| 第 6 课 | random 随机 |

- 让孩子自己说每一样能干什么，帮他把零散知识连成网。

### 第 3 步：游戏规则（幻灯片 3~4）
- 答对一题 +1 分，最后用 elif 评级。
- **记分牌**：`score = 0`，答对就 `score = score + 1`。
- "分数 = 分数 + 1"第一次见，但很好懂：把旧分数加 1 再放回去。

### 第 4 步：逐关讲解（幻灯片 5~8）
- 第 1 关 数字题：`int(input(...))` + `==`（第 8 课）。
- 第 2 关 脑筋急转弯：`input()` + 字符串 `==`（带引号）。
- 彩蛋关：`random.randint`（第 6 课）+ `%` 判单双（第 5 课）。
- 结算：`if/elif/else` 评级（第 9 课）。
- 强调：每一关都用到了之前的知识，这就是复习的意义。

### 第 5 步：动手改着玩（幻灯片 9）
- 改题目：把 `3 + 5` 换成别的算式。
- 加一关：自己出一道脑筋急转弯。
- 改评级分数：满分 4 分改成别的要求。

---

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| `score = 0` | 记分牌，先放 0 |
| `score = score + 1` | 答对加分（旧分数 +1 再放回去） |
| `int(input(...))` | 数字题要变数字 |
| `input(...)` | 文字题直接比字符串（带引号） |
| `if / elif / else` | 判断 + 评级 |

---

## 孩子可能卡在哪

1. **`score = score + 1` 觉得奇怪** → 右边先算（旧分 +1），再把结果放回左边。
2. **数字题忘了 `int()`** → 文字和数字比会报错，记住 `int(input(...))`。
3. **字符串题没加引号** → 答案是文字，比较要写 `== "水"`（带引号）。
4. **中文答案对不上** → Windows 控制台输入中文偶尔乱码，卡住就换数字题。
5. **记分从 0 开始** → 分数要先 `score = 0`，否则没地方加。
