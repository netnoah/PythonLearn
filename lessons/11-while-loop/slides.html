for 和 while

  • for：知道要重复几次（第 5 课）
  • while：不知道几次，重复到"条件不成立"
  • 猜数字：不知道几次能猜对 → while

while 语法

while 条件:
    # 条件对，就一直重复这里

条件变"错"时才停

数数

n = 1
while n <= 3:
    print("第", n, "次")
    n = n + 1

n 每次 +1，到 4 就停

小心死循环！

n = 1
while n <= 3:
    print(n)
    # 忘了 n = n + 1 ！

n 永远是 1，程序永远停不下来

按 Ctrl + C 能强行停下

升级猜数字

secret = random.randint(1, 100)
guess = 0          # 先放个肯定不对的数
times = 0

while guess != secret:
    guess = int(input("猜 1~100："))
    times = times + 1
    # 给提示……

提示：猜大猜小

if guess > secret:
    print("太大了！")
elif guess < secret:
    print("太小了！")
else:
    print("猜对啦！🎉")

第 9 课的 elif 又用上了

计次数

times = 0          # 开始 0 次
while ...:
    ...
    times = times + 1  # 每猜一次 +1

循环结束，times 就是你猜的次数
