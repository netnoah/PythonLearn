## 讲解流程

### 第 1 步：先看效果（3 分钟）
- 运行 `python demo.py`：先数 1、2、3，然后进入猜数字——反复猜，每次有"太大/太小"提示，猜对后告诉你猜了几次。
- 说："第 8 课只能猜一次，这一课用 while 一直猜到对为止。"

### 第 2 步：for 和 while 的区别（幻灯片 2）
- `for`：知道要重复几次（第 5 课）。
- `while`：不知道几次，重复到"条件不成立"。
- 猜数字不知道几次能猜对，所以用 while。

### 第 3 步：while 语法（幻灯片 3）
- `while 条件:` —— 条件对，就一直重复下面缩进的代码。
- 冒号和缩进（和第 5 课 for、第 8 课 if 一样）。

### 第 4 步：数数例子（幻灯片 4）
- `n` 从 1 开始，只要 `n <= 3` 就打印并 `n = n + 1`。
- 重点：循环体里必须改变 `n`，否则永远停不下来。

### 第 5 步：死循环（幻灯片 5）★重点
- 忘了 `n = n + 1`，n 永远是 1，条件永远成立，程序卡死。
- 应急：按 **Ctrl + C** 强行停下。
- 这是 while 最容易踩的坑，一定要讲。

### 第 6 步：升级猜数字（幻灯片 6~7）
- `while guess != secret:` —— 没猜对就一直猜。
- 循环里用 `if/elif/else` 给提示（第 9 课）。
- `guess` 先放 0（肯定不对），让循环能先跑起来。

### 第 7 步：计次数（幻灯片 8）
- `times` 从 0 开始，每猜一次 +1。
- 循环结束，`times` 就是猜的次数，还能用来评级。

### 第 8 步：动手改着玩（幻灯片 9）
- 把范围改成 1~1000。
- 加"最多 10 次"的限制（见挑战题）。
- 改成"石头剪刀布直到你赢"。

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| `while 条件:` | 条件对，就一直重复 |
| 改变条件 | 循环里要让它"慢慢变错"，否则死循环 |
| 死循环 | 忘了改条件，程序卡死，Ctrl+C 停下 |
| `guess = 0` | 先放个肯定不对的数，让循环先跑起来 |
| `times = times + 1` | 计次数 |

---

## 孩子可能卡在哪

1. **死循环** → 忘了在循环里改条件变量，程序卡死；教他 Ctrl+C。
2. **while 条件写错** → 想"没猜对就一直猜"，条件应该是 `!=`，不是 `==`。
3. **guess 没先赋值** → `while guess != secret` 里 guess 还没出生，报 NameError；先 `guess = 0`。
4. **冒号/缩进** → while 后要冒号，循环体要缩进。
5. **分不清 for 和 while** → for 知道次数，while 不知道次数。
