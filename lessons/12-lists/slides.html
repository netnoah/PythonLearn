藏宝箱

学 list 列表，把很多东西装进一个箱子！

藏宝箱 list

backpack = ["剑", "盾牌", "药水", "金币"]

一个箱子，装很多东西，按顺序排好

创建列表

列表名 = [东西1, 东西2, 东西3]

用方括号 [ ]，中间用逗号隔开

编号从 0 开始！

backpack[0]  →  剑     # 第 1 个
backpack[1]  →  盾牌   # 第 2 个
backpack[2]  →  药水   # 第 3 个

第 1 个是 [0]，不是 [1]！最容易错的地方

数一数：len()

print(len(backpack))   # 4

len = length（长度），数有几样

装新东西：append()

backpack.append("弓箭")

把"弓箭"塞进箱子最后面

按编号换掉

backpack[0] = "火焰剑"

把编号 0 的东西换成新的

小彩蛋：-1

backpack[-1]   # 最后一个

倒着数：-1 最后，-2 倒数第二……
