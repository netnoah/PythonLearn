# 第 12 课 讲稿：藏宝箱（list 列表）

> 目标：学会 list 列表——用一个"箱子"把很多东西按顺序存起来。
> 时长建议：25~30 分钟。第四单元第二课，为第 13 课"翻遍藏宝箱"（for 遍历列表）打基础。

---

## 课前准备

- 确认电脑有 Python。
- 打开 `slides.html`，准备好 `demo.py`。
- 本课在**命令行**（不用 turtle）。

---

## 讲解流程

### 第 1 步：先看效果（3 分钟）
- 运行 `python demo.py`：显示一个游戏背包，然后取东西、数数量、加装备、升级武器。
- 说："一个变量只能装一个东西；list 是一个'箱子'，能装一大堆。"

### 第 2 步：什么是 list（幻灯片 2~3）
- list = 藏宝箱，用方括号 `[ ]`，里面东西用逗号隔开。
- 例子：`backpack = ["剑", "盾牌", "药水", "金币"]`。

### 第 3 步：编号从 0 开始（幻灯片 4）★重点
- 第 1 个是 `[0]`，第 2 个是 `[1]`……
- 这是本课最大的坑，一定要反复强调，让孩子自己数一遍。
- 类比：一楼不是 1 楼，是 0 楼。

### 第 4 步：len() 数一数（幻灯片 5）
- `len(backpack)` 数有几样。
- len = length（长度）。

### 第 5 步：append() 装新东西（幻灯片 6）
- `backpack.append("弓箭")` 把东西塞到最后面。

### 第 6 步：按编号换掉（幻灯片 7）
- `backpack[0] = "火焰剑"` 把编号 0 的东西换掉。

### 第 7 步：小彩蛋 -1（幻灯片 8）
- `backpack[-1]` 是最后一个，`-2` 倒数第二。

### 第 8 步：动手改着玩（幻灯片 9）
- 改成自己的背包 / 购物清单。
- 试试 `backpack[-1]`、多 append 几样。

---

## 关键点（务必点到）

| 概念 | 一句话讲法 |
|---|---|
| list | 一个箱子装很多东西，按顺序排 |
| `[ ]` | 方括号创建列表，逗号隔开 |
| `[0]` | 第 1 个（从 0 数！） |
| `len()` | 数有几样 |
| `append()` | 塞新东西到最后 |

---

## 孩子可能卡在哪

1. **编号从 0 开始** → 以为 `[1]` 是第一个；反复练习。
2. **列表用 () 或 {} 创建** → 是 `[ ]`。
3. **忘了逗号** → `["剑" "盾牌"]` 会报错，中间要逗号。
4. **编号超出范围** → 4 样东西，写 `backpack[4]` 报 IndexError（最大是 3）。
5. **len 和 [ ] 分不清** → len 是"一共有几个"，`[i]` 是"第 i 个是啥"。
